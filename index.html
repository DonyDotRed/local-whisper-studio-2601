로컬 처리와 네트워크 사용 범위

음성·녹음·변환 결과는 브라우저 내부에서 처리됩니다. 최초 AI 모델 및 WebAssembly 엔진 로딩 시 CDN/Hugging Face에서 프로그램 파일과 모델 가중치를 내려받습니다. 음성 파일 자체를 해당 서버로 전송하는 코드는 포함하지 않습니다.

Local Whisper Studio 2.2 · Optimized GitHub Pages 브라우저 로컬 처리

사용 방법

  1. 오디오 파일을 추가하거나 마이크로 녹음합니다.
  2. M4A 등은 필요하면 WAV 변환으로 16 kHz mono WAV로 저장할 수 있습니다.
  3. 처음에는 빠른 전사 · Tiny 프리셋을 권장합니다. 5분 테스트에 가장 적합합니다.
  4. AI 모델 준비를 누르면 선택한 Whisper 모델을 최초 1회 다운로드하고 브라우저에 캐시합니다.
  5. 텍스트 변환을 실행합니다. WebGPU가 있으면 GPU를 우선 사용하며, 각 Whisper chunk 완료 시 실제 진행률을 표시합니다.
  6. 결과를 TXT, Markdown, SRT, VTT, JSON으로 저장할 수 있습니다.

권장 환경

최신 Chrome/Edge + WebGPU 지원 GPU. 5~30분 파일은 Tiny 또는 Base를 권장합니다. Small/Large는 정확도가 필요하고 GPU 여유가 있을 때 사용하세요. GitHub Pages의 CPU(WASM)는 단일 스레드가 될 수 있으므로 Tiny가 가장 안정적입니다.
